# 九重天堂 — 羁绊机制设计方案

> 适用范围：PVE 肉鸽自走棋模式  
> 设计目标：用六个具有宗教信仰的国家代号提供主 Build 方向，用 DND 职业/小分支保留角色战斗模板差异，用六维属性与阵营标签提供轻量数值成长，让玩家在“酒馆招募 → 阵容组建 → 战斗部署 → 结算奖励”的循环中持续形成取舍。

---

## 一、设计原则

1. **信仰国家是主羁绊**  
   主羁绊不再由 DND 职业大分支提供，而由角色所属的六个宗教信仰国家提供。国家决定阵容的核心机制方向：国教律法、战场仪式、国家军制、神术/奥术传统、召唤对象、资源循环等。玩家看到某个国家成型时，应明显感觉“这套阵容的打法变了”。当前阶段先使用 `nation_a`~`nation_f` 与 `国A`~`国F` 作为代号。
2. **六维与阵营是小羁绊**  
   力量、敏捷、体质、智力、感知、魅力，以及守序、混沌、善良、邪恶、中立只提供属性数值、局内资源、酒馆资源或结算资源层面的提升。它们负责强化 Build，而不抢主羁绊的机制位置。

3. **DND 职业/小分支塑造角色模板，不再作为主羁绊类型**  
   每个 DND 职业大分支下仍包含多个小分支。职业与小分支用于决定单个角色的技能、攻击范围、索敌逻辑和战斗定位；MVP 阶段不建议让职业或小分支也成为独立羁绊，避免 UI 和理解成本过高。角色可以是“圣武士/奉献誓言”这样的战斗模板，但其主羁绊贡献来自所属国家，例如 `nation_a`。
4. **同名角色不重复计数**  
   羁绊按“不同角色”计数。相同角色升星只增强角色本体，不额外增加羁绊数量，避免肉鸽招募被单一重复刷牌策略绑死。

5. **战斗羁绊按已部署单位实时计算**  
   主羁绊和战斗属性类小羁绊只统计场上已部署的友方单位。资源类奖励在战斗胜利时，按本场战斗结束前的最终部署快照结算。

6. **羁绊能力拥有层数成长**  
   参考“卫戍协议”式的层数体验，每个已激活羁绊拥有 `0-999` 层。触发人数决定羁绊档位，层数决定档位内可变数值的强度。主羁绊的层数成长称为“羁绊效果”，它应成为肉鸽后期对抗战场强度膨胀的核心引擎，而不是锦上添花的小数值。小羁绊的成长思路与主羁绊接近但略弱，只能提供数值提升，不能提供机制变化。层数主要强化百分比属性、伤害、治疗、护盾、减伤、暴击等战斗数值；商店刷新花费降低、商店价格降低、部署费用降低、金币额外获得等资源/经济类加成不随层数变化。

7. **8 人部署上限决定主流构筑结构**  
   默认战场最多部署 8 名角色。主流成型结构是 `6 人主羁绊 + 3 人小羁绊`，通过 1 名角色同时贡献主羁绊与小羁绊来完成重叠，即 `6 + 3 - 1 = 8`。玩家也可以放弃 6 人主羁绊，选择开启 `3 个 3 人小羁绊`，用多条数值曲线叠加来配合角色本体和遗物。

## 二、角色标签结构
每个可招募角色至少拥有以下标签：

```text
角色
├── 国家主羁绊 class_group：nation_a~nation_f 之一（临时沿用 class_group 字段）
├── DND 职业模板 class_id：barbarian/bard/cleric...
├── 职业小分支 subclass：该职业下的专精路线
├── 六维标签 stat_tags：1 个主属性 + 0~1 个副属性
├── 阵营标签 alignment_tags：1~2 个阵营轴标签
└── 稀有度/星级/技能组：用于肉鸽成长与数值缩放
```

> 字段说明：`class_group` 在代码中暂时保留原名，但语义已经从“职业大分支”改为“国家主羁绊代号”。后续若重构数据层，可将其改名为 `nation_group` 或 `faith_nation`。

六维标签：
| 标签 | 英文 | 定位 |
|------|------|------|
| 力量 | STR | 物理攻击、破甲、击退抗性 |
| 敏捷 | DEX | 攻速、闪避、暴击 |
| 体质 | CON | 生命、防御、治疗承受 |
| 智力 | INT | 技能伤害、技能冷却、法术资源 |
| 感知 | WIS | 治疗、护盾、异常抗性、索敌效率 |
| 魅力 | CHA | DP、金币、招募、团队增益数值 |

阵营标签采用 DND 阵营轴的拆分写法。一个角色可以是“守序善良”，在羁绊计数中同时提供 `守序` 和 `善良`；也可以是“混沌中立”，同时提供 `混沌` 和 `中立`；“绝对中立”只提供 `中立`。
| 标签 | 定位 |
|------|------|
| 守序 | 稳定、防御、阵型收益、资源返还 |
| 混沌 | 暴击、随机增幅、爆发收益 |
| 善良 | 治疗、护盾、保护、战后恢复 |
| 邪恶 | 吸血、斩杀、击杀收益 |
| 中立 | 泛用属性、最大资源、路线/商店稳定性 |

## 四、主羁绊：信仰国家

主羁绊按场上同一信仰国家代号的不同角色数量激活。当前阶段先不正式命名国家，只使用 `nation_a`~`nation_f` 与 `国A`~`国F`。国家是阵容机制方向，DND 职业是角色战斗模板，小羁绊仍由六维与阵营提供。

### 4.0 国家代号与当前职业模板映射

| 国家代号 | UI代号 | 临时信仰/国家方向 | 当前职业模板来源 | 基础角色数量 |
|----------|--------|-------------------|------------------|--------------|
| `nation_a` | 国A | 神职、誓言、守护 | Cleric、Paladin | 6 |
| `nation_b` | 国B | 奥术、工造、结界 | Wizard、Artificer | 6 |
| `nation_c` | 国C | 自然、巡猎、领域 | Druid、Ranger | 6 |
| `nation_d` | 国D | 潜行、武技、机动 | Monk、Rogue | 6 |
| `nation_e` | 国E | 军势、狂战、阵线 | Barbarian、Fighter | 6 |
| `nation_f` | 国F | 乐歌、血脉、契约 | Bard、Sorcerer、Warlock | 9 |

这个映射只用于 MVP 阶段快速落地。后续正式世界观确定后，可以把 `国A`~`国F` 替换成真实国家名、国教名、纹章、神祇或政治阵营；角色也可以从“按职业整组归国”改成“按角色背景归国”。

### 4.1 激活规则

| 数量 | 强度 | 说明 |
|------|------|------|
| 3 | 成型 | 国家机制出现，并提供第一段可随层数成长的数值 |
| 6 | 完全体 | 扩展国家机制，改变战斗节奏或提供强终局能力 |

主羁绊不再使用 2 人入门档。3 人触发是明确的 Build 承诺，6 人触发是核心阵容成型。

### 4.2 羁绊层数与激进曲线

每个国家主羁绊拥有独立层数，范围为 `0-999`。主羁绊激活后产生的层数强化统一称为“羁绊效果”。

```text
国家主羁绊层数 = min(999, 基础层数 + 角色星级层数 + 遗物层数 + 事件层数)
```

推荐来源：
| 来源 | 建议层数 |
|------|----------|
| 羁绊刚被激活 | 0 |
| 对应国家角色升星 | 每个星级 +5~20 |
| 国家/国教专属遗物 | +30~120 |
| 路线事件奖励 | +20~80 |
| Boss 战前强化 | +50~150 |

国家主羁绊的机制解锁由人数决定，机制中的可变数值由层数线性放大。为了匹配肉鸽后期战场强度，主羁绊曲线需要比小羁绊更激进：

```text
最终倍率/数值 = 档位基础值 + 层数 × 每层成长值
```

推荐满层目标：
| 羁绊类型 | 999 层目标 |
|----------|------------|
| 攻击/伤害型 | 核心输出最终约 8-10 倍 |
| 治疗/护盾型 | 有效治疗或有效护盾约 6-8 倍 |
| 防御/承伤型 | 有效生命或减伤收益约 5-7 倍 |
| 召唤/装置型 | 召唤物或装置综合效率约 6-8 倍 |
| 控制/功能型 | 不单纯拉长控制时间，优先提高覆盖率、附带伤害或触发频率 |

### 4.3 六个国家主羁绊草案

| 国家 | 主羁绊名称 | 3 人触发 | 6 人触发 | 羁绊层数成长示例 |
|------|------------|----------|----------|------------------|
| 国A | 国A信条 | 周期性为最低生命友军生成圣盾/守护，神职与誓言型单位获得额外承伤效率 | 首次致命伤改为大额护盾，护盾破裂时治疗附近友军 | 护盾/承伤倍率 `1.25 + 层数×0.006`，上限 7 倍 |
| 国B | 国B信条 | 施法或技能命中时叠加奥术/工造印记，印记爆发造成额外伤害 | 印记可连锁至附近敌人；装置/结界周期性刷新 | 印记爆发倍率 `1.4 + 层数×0.008`，上限 9.5 倍 |
| 国C | 国C信条 | 战场生成自然领域，领域内友军获得恢复或目标标记收益 | 标记转移并扩散，自然领域可召唤临时伙伴或藤蔓控制 | 标记/领域效率 `1.25 + 层数×0.0065`，上限 8 倍 |
| 国D | 国D信条 | 机动单位获得周期性突袭/连击，攻击未锁定自己的敌人时增伤 | 突袭后短暂隐匿或位移，低血目标获得斩杀收益 | 突袭倍率 `1.5 + 层数×0.0085`，上限 10 倍 |
| 国E | 国E信条 | 前排与近战单位获得阵线层数，提供攻击与减伤 | 阵线满层后触发压制/溅射/破甲，首次濒死获得短暂锁血 | 阵线伤害倍率 `1.35 + 层数×0.008`，上限 9.5 倍；减伤有封顶 |
| 国F | 国F信条 | 周期性为队伍提供最短板数值激励，契约/血脉型单位获得额外充能 | 激励溢出转为技能冷却或资源回流，契约目标共享收益 | 激励主倍率 `1.2 + 层数×0.0068`，上限 8 倍 |

国家主羁绊允许改变攻击模式、召唤对象、索敌策略、技能触发条件和战斗循环。主羁绊中的层数数值应服务于该国家机制，例如信条护盾强度、国教印记爆发、自然领域效率、突袭倍率、阵线压制、激励强度；避免只给“全队攻击 +X%”这类脱离机制的大量裸数值。

### 4.4 羁绊效果避坑规则

羁绊效果是玩家肉鸽 Build 的主要正反馈，因此宁可强得明显，也不要设计成“理论很强、实战不触发”。每个羁绊在定稿前需要检查以下问题：

1. **核心收益是否稳定触发**  
   核心收益应来自常驻、周期、攻击、施法、受击、部署等高频条件。击杀、暴击、低血、溢出治疗、濒死等条件只能作为额外奖励。
2. **触发条件是否会被战场强度反向压制**  
   如果敌人伤害越高，某个收益越难触发，这个收益就不适合作为核心。例如“治疗溢出转护盾”在低压局很容易触发，但高压局治疗几乎都用于补血，护盾反而消失，玩家会觉得自己选错了 Build。
3. **是否存在逆风保底**  
   每个防御、治疗、控制类羁绊都需要逆风保底。例如国A可以“周期性给最低血友军保底护盾”，溢出治疗只作为额外收益，而不是核心触发条件。
4. **层数是否提供可感知的爆发成长**  
   主羁绊 999 层时必须让玩家肉眼看出 Build 成型。输出型满层目标约 8-10 倍，治疗/护盾型约 6-8 倍，承伤型约 5-7 倍。
5. **资源收益是否被错误放大**  
   商店刷新、商店价格、金币、DP、部署费用等经济项不参与层数线性成长。经济项可以作为 6 人档或遗物奖励，但不能因为 999 层变成无限滚雪球。

## 五、小羁绊：六维属性

小羁绊的设计思路与主羁绊接近，但强度略弱于主羁绊，且只能提供数值提升。小羁绊不能改变攻击模式、索敌逻辑、召唤物类型、技能触发规则、自动施法频率等机制内容。

### 5.1 激活规则

六维小羁绊按场上拥有对应属性标签的不同角色数量激活，推荐档位为 `2/3`。

| 数量 | 强度定位 |
|------|----------|
| 2 | 明确方向 |
| 3 | Build 成型 |

六维小羁绊同样拥有 `0-999` 层。六维的主要作用是提供可被层数线性放大的百分比属性，因此每个已激活六维至少需要有一条“初级可变加成”。资源相关收益可以出现在 3 人档，但不参与层数成长。

推荐满层目标：

| 小羁绊类型 | 999 层目标 |
|------------|------------|
| 单项攻击/技能/治疗属性 | 约 4-5 倍 |
| 防御/生命/承伤属性 | 约 3.5-5 倍 |
| 暴击/破甲/冷却等副属性 | 约 2-3.5 倍或固定上限 |
| 资源/经济项 | 固定值，不随层数成长 |

### 5.2 六维效果草案

| 六维 | 2 人触发 | 3 人触发 | 层数成长示例 |
|------|----------|----------|--------------|
| 力量 STR | 物理攻击倍率提升 | 额外获得破甲 | 物理攻击倍率 `1.15 + 层数×0.0038`，上限 5 倍；破甲 `10% + 层数×0.025%`，上限 35% |
| 敏捷 DEX | 攻速倍率提升 | 额外获得闪避与暴击 | 攻速倍率 `1.12 + 层数×0.0032`，上限 4.3 倍；暴击 `8% + 层数×0.02%`，上限 30% |
| 体质 CON | 最大生命倍率提升 | 额外获得防御与治疗承受 | 最大生命倍率 `1.2 + 层数×0.0038`，上限 5 倍；防御倍率 `1.1 + 层数×0.0025`，上限 3.5 倍 |
| 智力 INT | 技能伤害倍率提升 | 额外获得技能冷却缩减 | 技能伤害倍率 `1.2 + 层数×0.004`，上限 5.2 倍；技能冷却缩减 `8% + 层数×0.025%`，上限 35% |
| 感知 WIS | 治疗/护盾倍率提升 | 额外获得异常抗性与索敌范围 | 治疗/护盾倍率 `1.15 + 层数×0.0035`，上限 4.6 倍；异常抗性 `10% + 层数×0.025%`，上限 35% |
| 魅力 CHA | 团队增益倍率提升 | 额外获得初始 DP 与招募价格降低 | 团队增益倍率 `1.1 + 层数×0.003`，上限 4 倍；初始 DP、招募价格降低固定，不随层数增加 |

注意：`索敌范围 +1` 虽然影响战斗表现，但本质是数值型范围修正，不改变索敌机制本身。若需要让索敌范围随层数成长，建议使用离散断点，例如层数达到 300/700 时分别 `+1`，不要每层线性增加格数。

## 六、小羁绊：五阵营

### 6.1 激活规则

阵营小羁绊按场上拥有对应阵营标签的不同角色数量激活，推荐档位为 `2/3`。阵营可以与六维同时存在，因此单个角色通常会贡献：

```text
1 个国家主羁绊
1~2 个六维小羁绊
1~2 个阵营小羁绊
```

### 6.2 阵营效果草案

| 阵营 | 2 人触发 | 3 人触发 | 层数成长示例 |
|------|----------|----------|--------------|
| 守序 | 有效防御倍率提升 | 额外获得撤退返还与部署费用降低 | 有效防御倍率 `1.12 + 层数×0.003`，上限 4 倍；撤退返还、部署费用降低固定 |
| 混沌 | 暴击伤害倍率提升 | 额外获得暴击率与刷新费用降低 | 暴击伤害倍率 `1.15 + 层数×0.0035`，上限 4.5 倍；刷新费用降低固定 |
| 善良 | 每波开始全队回复倍率提升 | 额外获得开波护盾倍率 | 回复/护盾倍率 `1.1 + 层数×0.0032`，上限 4.2 倍 |
| 邪恶 | 攻击吸血倍率提升 | 额外获得击杀金币概率 | 攻击吸血倍率 `1.1 + 层数×0.0032`，上限 4.2 倍；击杀金币概率固定 |
| 中立 | 全队泛用属性倍率提升 | 额外获得最大 DP、胜利金币与商店刷新费用降低 | 泛用属性倍率 `1.05 + 层数×0.0025`，上限 3.5 倍；最大 DP、胜利金币、刷新费用降低固定 |

阵营收益尽量控制在“经济与数值偏好”层面。比如混沌可以强化暴击倍率和暴击率，但不应获得“随机改变技能形态”这种主机制效果；邪恶可以有攻击吸血和击杀收益，但不应变成完整的召唤/献祭玩法。

阵营中涉及商店价格、刷新费用、部署费用、胜利金币、击杀金币、初始 DP、最大 DP 的加成，均视作资源/经济项，不适用层数线性成长。它们只由触发档位、遗物或事件直接改写。

## 七、8 人部署与羁绊组合

战场部署角色数量上限暂定为 8 人。这个上限会直接决定羁绊组合的主流形态。

### 7.1 主流结构：6 主羁绊 + 3 小羁绊

```text
6 人主羁绊 + 3 人小羁绊 - 1 名重叠角色 = 8 个部署位
```

这是默认推荐玩法。玩家围绕一个信仰国家凑出 6 人主羁绊，获得完整机制；再用一个 3 人小羁绊补强核心数值。

示例结构：

```text
国C主羁绊 6
敏捷小羁绊 3

部署位：
1. 国C角色 A
2. 国C角色 B
3. 国C角色 C
4. 国C角色 D
5. 国C角色 E
6. 国C角色 F / 敏捷    # 重叠角色
7. 敏捷角色 G
8. 敏捷角色 H
```

其中 `国C角色 F / 敏捷` 同时贡献 1 点国C主羁绊和 1 点敏捷小羁绊，所以 8 个部署位即可同时完成 `6/6` 主羁绊与 `3/3` 小羁绊。

### 7.2 数值拼图结构：3 个 3 人小羁绊

玩家也可以放弃 6 人主羁绊，选择开启 3 个 3 人小羁绊，用多条数值曲线叠加来配合角色本体、装备和遗物。

```text
敏捷小羁绊 3
混沌小羁绊 3
邪恶小羁绊 3
```

由于单个角色可以拥有多个小羁绊标签，例如 `敏捷 + 混沌` 或 `敏捷 + 邪恶`，3 个小羁绊不一定需要 9 个部署位。这个路线的特点是机制变化较少，但数值密度高，适合依赖角色技能本体或遗物触发的阵容。

### 7.3 平衡基准

| 结构 | 机制强度 | 数值强度 | 设计定位 |
|------|----------|----------|----------|
| 6 主 + 3 小 | 最高 | 高 | 标准终局 Build |
| 3 主 + 3 主 + 3 小 | 中高 | 中高 | 双职业混合 Build |
| 3 小 + 3 小 + 3 小 | 低 | 最高 | 数值拼图 Build |
| 3 主 + 多个 2 小 | 中 | 灵活 | 过渡期或应急 Build |

主羁绊负责打开机制上限，小羁绊负责把数值推高。小羁绊可以很强，但不能用数值强度反向替代主羁绊的机制辨识度。

## 九、数值与叠加规则

1. **层数只放大战斗数值**  
   羁绊层数范围为 `0-999`，常规公式为 `最终加成/倍率 = 档位基础值 + 层数 × 每层成长值`。适用对象包括攻击、生命、防御、攻速、暴击、伤害、治疗、护盾、减伤、异常抗性等。商店刷新花费降低、商店价格降低、部署费用降低、撤退返还、初始 DP、最大 DP、胜利金币、击杀金币等资源/经济项不适用层数线性成长。

2. **初级加成必须有可变数值**  
   每个已激活羁绊的第一档效果都应包含至少一条可随层数变化的数值，通常为百分比加成。例如 `物理攻击倍率 1.15 + 层数×0.0038`。如果某个主羁绊第一档是纯机制，例如“召唤藤蔓”，也需要给藤蔓的减速、持续时间、生命值或触发伤害配置层数成长。

3. **同类加成先相加，最后统一乘算**  
   例如攻击力最终值：`基础攻击 × (1 + 力量加成 + 装备加成 + 临时 Buff 加成)`。

4. **主羁绊机制触发后，再吃小羁绊数值修正**  
   例如游荡者的潜袭伤害属于主羁绊机制；潜袭最终伤害仍然可以被敏捷、力量、邪恶等小羁绊数值修正影响。

5. **经济收益设置单场上限**  
   击杀金币、胜利金币、刷新费用折扣需要设置软上限，避免某个经济阵营滚雪球过快。建议单场额外金币不超过基础奖励的 30%。因为经济项不吃层数，所以它们更适合由触发档位、遗物品质或路线事件来调整。

6. **技能冷却缩减设置全局上限**  
   所有来源合计冷却缩减不超过 40%，避免技能系统失控。

7. **防御与闪避分开限制**  
   防御适合稳定减伤，闪避适合波动收益。闪避建议上限 35%，否则自走棋战斗结果会过度随机。

## 十、Godot 实现落点

### 10.1 数据结构扩展

当前 `ClassTemplate` 已经承担职业模板职责，建议拆出更清晰的角色定义层：

```text
CharacterDefinition
├── character_id
├── display_name
├── class_group          # nation_a/nation_b/...（国家主羁绊代号）
├── subclass_id          # champion/hunter/evoker...
├── stat_tags            # ["DEX", "WIS"]
├── alignment_tags       # ["CHAOTIC", "NEUTRAL"]
├── class_template_id    # 指向现有 ClassTemplate 或未来的分支模板
├── rarity
└── skill_ids
```

`ClassTemplate` 保留为“职业/小分支战斗模板”，继续决定：

- 部署费用
- 基础属性
- 攻击模式
- 攻击范围
- 索敌范围
- 姿态修正
- 技能列表
- 职业特性参数

### 10.2 新增 SynergyDefinition

```text
SynergyDefinition
├── synergy_id
├── display_name
├── type                 # MAIN_NATION / MINOR_STAT / MINOR_ALIGNMENT
├── tag                  # nation_a / DEX / LAWFUL
├── thresholds           # 主羁绊 [3, 6]；小羁绊 [2, 3]
├── layer                # 当前层数，0-999
├── layer_sources        # 星级/遗物/事件/奖励等来源明细
├── scalable_modifiers   # 随层数线性成长的战斗数值
├── fixed_modifiers      # 不随层数成长的资源/经济数值
└── mechanic_id          # 主羁绊使用，如 nation_a_creed
```

推荐的 `scalable_modifiers` 数据形态：

```text
{
  "stat": "marked_damage_multiplier",
  "curve": "linear_cap",
  "base": 1.4,
  "per_layer": 0.008,
  "max_value": 9.5
}
```

推荐的 `fixed_modifiers` 数据形态：

```text
{
  "resource": "shop_discount_percent",
  "value": 0.05
}
```

资源/经济项必须进入 `fixed_modifiers`，不允许配置 `per_layer`。

### 10.3 新增 SynergyManager

建议路径：

```text
game/scripts/synergy/synergy_manager.gd
game/scripts/synergy/synergy_definition.gd
game/scripts/synergy/synergy_effects.gd
```

核心职责：

```text
SynergyManager
├── listen deployed_units_changed
├── collect tags from deployed HeroUnit
├── calculate active tiers and layers
├── emit synergy_changed(active_synergies)
├── apply scalable numeric modifiers to UnitBase
├── apply fixed resource modifiers to ResourceManager/RoguelikeManager
└── dispatch mechanic hooks to profession-specific effects
```

### 10.4 推荐信号

```text
DeploymentSystem.unit_deployed(unit)
DeploymentSystem.unit_retreated(unit)
BattleManager.battle_started()
BattleManager.battle_ended(result)
SynergyManager.synergy_changed(active_synergies)
SynergyManager.resource_bonus_ready(bonus_payload)
```

### 10.5 UI 展示

在战斗 UI 中新增一个羁绊面板：

- 画面顶部中间显示拥有的羁绊，图标为正方形，已激活的为天蓝色，未激活的为灰色
- 每个羁绊图标的上方有激活进度提示灯，形状为2/3个扁长小矩形，左右两边与图标正方形对齐，中间有空隙
- 图标居中排列，超过最长范围时增加一排空间
- 羁绊层数只使用单一的数字，在图标内最底部居中显示，增强与图标的对比度
- 羁绊显示顺序为激活的优先，其次层数高的优先，再次是主羁绊优先，羁绊间按文档中的顺序排序
- 羁绊可以通过点击显示说明，显示区域与羁绊栏宽度相同，位于羁绊栏下方并在游戏画面中央展开
- 羁绊说明显示羁绊图标，羁绊名称，已激活人数`2/3`，详细说明，该盟约对应的角色图标（使用与商店相同的图标）
- 酒馆招募卡上显示该角色能补齐的羁绊，例如 `游侠`、`敏捷`、`中立`

## 十三、后续可扩展方向

1. **小分支专属遗物**  
   小分支不直接成为羁绊，但可以与肉鸽遗物绑定。例如“战斗大师手册”只强化战士-战斗大师角色。

2. **阵营事件节点**  
   地图节点可以检测队伍阵营倾向，例如守序队伍更容易获得秩序神殿奖励，混沌队伍更容易触发高风险高收益事件。

3. **多职业角色**  
   高稀有度角色可以拥有双国家背景，例如“国E/国B”的奥法骑士，同时贡献两个国家主羁绊，但部署费用更高。

4. **职业反制敌人**  
   敌方阵容也可以携带弱羁绊标签，让玩家在路线选择时根据已有 Build 判断风险。
