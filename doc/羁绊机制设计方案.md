# 九重天堂 — 羁绊机制设计方案

> 适用范围：PVE 肉鸽自走棋模式  
> 设计目标：以单一国家“瑞莫里诺”作为背景母体，用境内领地、组织、信仰流派与传承盟约提供主 Build 方向；用 DND 职业/小分支保留角色战斗模板差异，用六维属性与阵营标签提供轻量数值成长，让玩家在“酒馆招募 → 阵容组建 → 战斗部署 → 结算奖励”的循环中持续形成取舍。

---

## 一、设计原则

1. **瑞莫里诺盟约是主羁绊**  
   主羁绊不再由 DND 职业大分支提供，也不再直接等同于国家。当前世界观以瑞莫里诺为单一国家，主羁绊来自其境内领地、组织、信仰流派或传承盟约，例如安马里特森林的瘴林威胁、莱茵刻伯的骑士律法、月神邪教的窥探禁忌等。玩家看到某个盟约成型时，应明显感觉“这套阵容的打法变了”。
2. **六维与阵营是小羁绊**  
   力量、敏捷、体质、智力、感知、魅力，以及守序、混沌、善良、邪恶、中立只提供属性数值、局内资源、酒馆资源或结算资源层面的提升。它们负责强化 Build，而不抢主羁绊的机制位置。

3. **DND 职业/小分支塑造角色模板，不再作为主羁绊类型**  
   每个 DND 职业大分支下仍包含多个小分支。职业与小分支用于决定单个角色的技能、攻击范围、索敌逻辑和战斗定位；MVP 阶段不建议让职业或小分支也成为独立羁绊，避免 UI 和理解成本过高。角色可以是“圣武士/奉献誓言”这样的战斗模板，但其主羁绊贡献来自所属盟约代号，例如 `remolino_law`。
4. **同名角色不重复计数**  
   羁绊按“不同角色”计数。相同角色升星只增强角色本体，不额外增加羁绊数量，避免肉鸽招募被单一重复刷牌策略绑死。

5. **战斗羁绊按已部署单位实时计算**  
   主羁绊和战斗属性类小羁绊只统计场上已部署的友方单位。资源类奖励在战斗胜利时，按本场战斗结束前的最终部署快照结算。

6. **羁绊能力拥有层数成长**  
   参考“卫戍协议”式的层数体验，每个已激活羁绊拥有 `0-999` 层。触发人数决定羁绊档位，层数决定档位内可变数值的强度。主羁绊的层数成长称为“羁绊效果”，它应成为肉鸽后期对抗战场强度膨胀的核心引擎，而不是锦上添花的小数值。小羁绊的成长思路与主羁绊接近但略弱，只能提供数值提升，不能提供机制变化。层数主要强化百分比属性、伤害、治疗、护盾、减伤、暴击等战斗数值；商店刷新花费降低、商店价格降低、部署费用降低、金币额外获得等资源/经济类加成不随层数变化。

7. **8 人部署上限决定主流构筑结构**  
   默认战场最多部署 8 名角色。主流成型结构是 `6 人主羁绊 + 3 人小羁绊`，通过 1 名角色同时贡献主羁绊与小羁绊来完成重叠，即 `6 + 3 - 1 = 8`。玩家也可以放弃 6 人主羁绊，选择开启 `3 个 3 人小羁绊`，用多条数值曲线叠加来配合角色本体和遗物。

## 二、角色标签结构
每个可招募角色至少拥有以下标签：

```text
角色
├── 主羁绊 class_group：瑞莫里诺盟约临时代号之一（临时沿用 class_group 字段）
├── DND 职业模板 class_id：barbarian/bard/cleric...
├── 职业小分支 subclass：该职业下的专精路线
├── 六维标签 stat_tags：1 个主属性 + 0~1 个副属性
├── 阵营标签 alignment_tags：1~2 个阵营轴标签
└── 稀有度/星级/技能组：用于肉鸽成长与数值缩放
```

> 字段说明：`class_group` 在代码中暂时保留原名，但语义已经从“职业大分支”改为“主羁绊临时代号”。当前代码中 `main_nation`、`nation` 等命名也暂作历史字段保留，文档语义统一理解为瑞莫里诺境内的盟约/领地/组织流派。

六维标签：
| 标签 | 英文 | 定位 |
|------|------|------|
| 力量 | STR | 物理攻击、破甲、击退抗性 |
| 敏捷 | DEX | 攻速、闪避、暴击 |
| 体质 | CON | 生命、防御、治疗承受 |
| 智力 | INT | 技能伤害、技能冷却、法术资源 |
| 感知 | WIS | 治疗、护盾、异常抗性、索敌效率 |
| 魅力 | CHA | DP、金币、招募、团队增益数值 |

阵营标签采用 DND 阵营轴的拆分写法。一个角色可以是“守序善良”，在羁绊计数中同时提供 `守序` 和 `善良`；也可以是“混沌中立”，同时提供 `混沌` 和 `中立`；“绝对中立”只提供 `中立`。
| 标签 | 定位 |
|------|------|
| 守序 | 稳定、防御、阵型收益、资源返还 |
| 混沌 | 暴击、随机增幅、爆发收益 |
| 善良 | 治疗、护盾、保护、战后恢复 |
| 邪恶 | 吸血、斩杀、击杀收益 |
| 中立 | 泛用属性、最大资源、路线/商店稳定性 |

## 四、主羁绊：瑞莫里诺盟约

主羁绊按场上同一盟约代号的不同角色数量激活。当前阶段从瑞莫里诺的领地、组织、信仰流派与传承背景中抽取七种主羁绊：`anmarit`、`laferida`、`naka`、`remolino_law`、`moon_cult`、`kroen_trench`、`tro_poem`。盟约决定阵容机制方向，DND 职业是角色战斗模板，小羁绊仍由六维与阵营提供。

### 4.0 盟约代号与当前职业模板映射

| 盟约代号 | UI 名称 | 背景依据 | 主机制方向 | 当前职业模板来源 | 基础角色数量 |
|----------|---------|----------|------------|------------------|--------------|
| `anmarit` | 瘴林威胁 | 安马里特森林，巫族、诅咒与瘴气 | 中毒、瘴气 DOT、范围扩散 | Rogue、Warlock | 6 |
| `laferida` | 扭曲生命 | 拉费里达平原，自然共生与生命异化 | 自然值、减速、爆条伤害 | Druid、Ranger | 6 |
| `naka` | 龙焰吐息 | 拉贝尔领地的考特火山与龙焰传承 | 火属性、灼烧、点燃、爆炸 | Barbarian、Sorcerer | 6 |
| `remolino_law` | 骑士律法 | 莱茵刻伯，瑞莫里诺首都与兰博明公爵领 | 防御、伤害均摊、律法反击 | Fighter、Paladin | 6 |
| `moon_cult` | 窥探禁忌 | 月神邪教与禁忌魔法 | 易伤、死亡爆发、诅咒处决 | Cleric、Wizard | 6 |
| `kroen_trench` | 不灭战壕 | 克罗恩伯爵领沙特尔地区 | 移速、闪避、闪避后增伤 | Monk、Artificer | 6 |
| `tro_poem` | 十一长诗 | 特罗群岛与金雀伯爵领的长诗传统 | 范围祝福、技能冷却缩减 | Bard | 3 |

这个映射用于 MVP 阶段快速落地。当前仍按职业模板整组归入盟约，保证多数盟约都有足够角色支撑 3/6 人触发；`十一长诗` 先保留 3 人触发样本，6 人档可通过后续新增角色、双盟约角色或测试覆盖验证。后续可以改成按具体角色背景归属盟约，而不是按职业整组绑定。

### 4.1 激活规则

| 数量 | 强度 | 说明 |
|------|------|------|
| 3 | 成型 | 盟约机制出现，并提供第一段可随层数成长的数值 |
| 6 | 完全体 | 扩展盟约机制，改变战斗节奏或提供强终局能力 |

主羁绊不再使用 2 人入门档。3 人触发是明确的 Build 承诺，6 人触发是核心阵容成型。

### 4.2 羁绊层数与激进曲线

每个主羁绊拥有独立层数，范围为 `0-999`。主羁绊激活后产生的层数强化统一称为“羁绊效果”。

```text
主羁绊层数 = min(999, 基础层数 + 角色星级层数 + 遗物层数 + 事件层数)
```

推荐来源：
| 来源 | 建议层数 |
|------|----------|
| 羁绊刚被激活 | 0 |
| 对应盟约角色升星 | 每个星级 +5~20 |
| 盟约/组织专属遗物 | +30~120 |
| 路线事件奖励 | +20~80 |
| Boss 战前强化 | +50~150 |

主羁绊的机制解锁由人数决定，机制中的可变数值由层数线性放大。为了匹配肉鸽后期战场强度，主羁绊曲线需要比小羁绊更激进：

```text
最终倍率/数值 = 档位基础值 + 层数 × 每层成长值
```

推荐满层目标：
| 羁绊类型 | 999 层目标 |
|----------|------------|
| 攻击/伤害型 | 核心输出最终约 8-10 倍 |
| 治疗/护盾型 | 有效治疗或有效护盾约 6-8 倍 |
| 防御/承伤型 | 有效生命或减伤收益约 5-7 倍 |
| 召唤/装置型 | 召唤物或装置综合效率约 6-8 倍 |
| 控制/功能型 | 不单纯拉长控制时间，优先提高覆盖率、附带伤害或触发频率 |

### 4.3 七个主羁绊草案

| 盟约 | 3 人触发 | 6 人触发 | 羁绊层数成长示例 |
|------|----------|----------|------------------|
| 瘴林威胁 | 英雄攻击附带 `层数系数%` 攻击力的毒属性层数；毒层随时间衰减，并根据层数造成可累加 DOT 伤害 | DOT 伤害变为小范围群体伤害，适合处理怪海 | 毒层攻击力系数 `0.60 + 层数×0.009`，上限 9.5 倍 |
| 扭曲生命 | 英雄攻击积累自然值；自然值满时清空并造成 `层数系数%` 减速，减速时长固定 | 自然值爆条额外造成 `层数系数%` 攻击力的属性伤害，取所有积累自然值英雄中的最高攻击力结算 | 减速 `20% + 层数×0.05%`，上限 70%；爆条伤害倍率 `1.0 + 层数×0.008`，上限 9 倍 |
| 龙焰吐息 | 英雄攻击力提升 `层数系数%`，攻击附带灼烧值；灼烧值满时清空并点燃敌人 | 英雄对燃烧状态敌人的伤害提升，且有 `层数系数%` 概率额外造成一次爆炸伤害 | 攻击倍率 `1.30 + 层数×0.008`，上限 9 倍；燃烧增伤 `1.25 + 层数×0.0075`，上限 8.5 倍；爆炸概率上限 70% |
| 骑士律法 | 盟约成员防御提升；成员受到攻击时，先按被攻击者防御计算实际伤害，再转化为生命百分比并由所有存活成员均摊 | 每个攻击盟约成员的敌人受到律法反击，伤害等于全体存活成员攻击力总和的 `层数系数%`，无视防御 | 防御倍率 `1.25 + 层数×0.0048`，上限 6 倍；反击系数 `0.35 + 层数×0.0065`，上限 7 倍 |
| 窥探禁忌 | 敌人承受伤害提升；被英雄攻击后 3 秒内死亡时，触发基于攻击者攻击力的范围禁忌爆发 | 被英雄攻击后的敌人若在 3 秒内生命低于攻击者攻击力的 `层数系数%`，立刻被诅咒处决 | 易伤倍率 `1.25 + 层数×0.0075`，上限 8.5 倍；死亡爆发系数 `0.90 + 层数×0.008`，上限 8.5 倍；处决阈值 `0.80 + 层数×0.0075`，上限 8 倍 |
| 不灭战壕 | 英雄移动速度提升，并按移动速度获得闪避率；核心收益来自受击时的稳定判定，不依赖击杀 | 成功闪避后，短时间获得随层数成长的伤害提升 | 移速倍率 `1.20 + 层数×0.004`，上限 5 倍；基础闪避 `8% + 层数×0.028%`，上限 35%，最终闪避暂封顶 45%；闪避后增伤 `1.30 + 层数×0.007`，上限 8 倍 |
| 十一长诗 | 盟约成员为攻击范围内友方提供祝福，使其获得该成员自身全属性的 `层数系数%` | 盟约成员释放技能时，有 `层数系数%` 概率使攻击范围内友方技能冷却减少固定秒数 | 祝福系数 `10% + 层数×0.19%`，上限 200%；冷却概率 `12% + 层数×0.05%`，上限 60%；冷却秒数 `0.5 + 层数×0.004`，上限 4 秒 |

主羁绊允许改变攻击模式、异常状态、伤害结算、范围扩散和战斗循环。主羁绊中的层数数值应服务于该盟约机制，例如毒层强度、自然值爆条、火焰增伤、律法反击、禁忌处决、闪避后增伤和长诗祝福；避免只给“全队攻击 +X%”这类脱离机制的大量裸数值。

### 4.4 羁绊效果避坑规则

羁绊效果是玩家肉鸽 Build 的主要正反馈，因此宁可强得明显，也不要设计成“理论很强、实战不触发”。每个羁绊在定稿前需要检查以下问题：

1. **核心收益是否稳定触发**  
   核心收益应来自常驻、周期、攻击、施法、受击、部署等高频条件。击杀、暴击、低血、溢出治疗、濒死等条件只能作为额外奖励。
2. **触发条件是否会被战场强度反向压制**  
   如果敌人伤害越高，某个收益越难触发，这个收益就不适合作为核心。例如“治疗溢出转护盾”在低压局很容易触发，但高压局治疗几乎都用于补血，护盾反而消失，玩家会觉得自己选错了 Build。
3. **是否存在逆风保底**  
   每个防御、治疗、控制类羁绊都需要逆风保底。例如拉费里达的自然值应通过攻击稳定积累，爆条减速只要求打满自然值，而不依赖击杀、暴击或溢出治疗。
4. **层数是否提供可感知的爆发成长**  
   主羁绊 999 层时必须让玩家肉眼看出 Build 成型。输出型满层目标约 8-10 倍，治疗/护盾型约 6-8 倍，承伤型约 5-7 倍。
5. **资源收益是否被错误放大**  
   商店刷新、商店价格、金币、DP、部署费用等经济项不参与层数线性成长。经济项可以作为 6 人档或遗物奖励，但不能因为 999 层变成无限滚雪球。

## 五、小羁绊：六维属性

小羁绊的设计思路与主羁绊接近，但强度略弱于主羁绊，且只能提供数值提升。小羁绊不能改变攻击模式、索敌逻辑、召唤物类型、技能触发规则、自动施法频率等机制内容。

### 5.1 激活规则

六维小羁绊按场上拥有对应属性标签的不同角色数量激活，推荐档位为 `2/3`。

| 数量 | 强度定位 |
|------|----------|
| 2 | 明确方向 |
| 3 | Build 成型 |

六维小羁绊同样拥有 `0-999` 层。六维的主要作用是提供可被层数线性放大的百分比属性，因此每个已激活六维至少需要有一条“初级可变加成”。资源相关收益可以出现在 3 人档，但不参与层数成长。

推荐满层目标：

| 小羁绊类型 | 999 层目标 |
|------------|------------|
| 单项攻击/技能/治疗属性 | 约 4-5 倍 |
| 防御/生命/承伤属性 | 约 3.5-5 倍 |
| 暴击/破甲/冷却等副属性 | 约 2-3.5 倍或固定上限 |
| 资源/经济项 | 固定值，不随层数成长 |

### 5.2 六维效果草案

| 六维 | 2 人触发 | 3 人触发 | 层数成长示例 |
|------|----------|----------|--------------|
| 力量 STR | 物理攻击倍率提升 | 额外获得破甲 | 物理攻击倍率 `1.15 + 层数×0.0038`，上限 5 倍；破甲 `10% + 层数×0.025%`，上限 35% |
| 敏捷 DEX | 攻速倍率提升 | 额外获得闪避与暴击 | 攻速倍率 `1.12 + 层数×0.0032`，上限 4.3 倍；暴击 `8% + 层数×0.02%`，上限 30% |
| 体质 CON | 最大生命倍率提升 | 额外获得防御与治疗承受 | 最大生命倍率 `1.2 + 层数×0.0038`，上限 5 倍；防御倍率 `1.1 + 层数×0.0025`，上限 3.5 倍 |
| 智力 INT | 技能伤害倍率提升 | 额外获得技能冷却缩减 | 技能伤害倍率 `1.2 + 层数×0.004`，上限 5.2 倍；技能冷却缩减 `8% + 层数×0.025%`，上限 35% |
| 感知 WIS | 治疗/护盾倍率提升 | 额外获得异常抗性与索敌范围 | 治疗/护盾倍率 `1.15 + 层数×0.0035`，上限 4.6 倍；异常抗性 `10% + 层数×0.025%`，上限 35% |
| 魅力 CHA | 团队增益倍率提升 | 额外获得初始 DP 与招募价格降低 | 团队增益倍率 `1.1 + 层数×0.003`，上限 4 倍；初始 DP、招募价格降低固定，不随层数增加 |

注意：`索敌范围 +1` 虽然影响战斗表现，但本质是数值型范围修正，不改变索敌机制本身。若需要让索敌范围随层数成长，建议使用离散断点，例如层数达到 300/700 时分别 `+1`，不要每层线性增加格数。

## 六、小羁绊：五阵营

### 6.1 激活规则

阵营小羁绊按场上拥有对应阵营标签的不同角色数量激活，推荐档位为 `2/3`。阵营可以与六维同时存在，因此单个角色通常会贡献：

```text
1 个主羁绊
1~2 个六维小羁绊
1~2 个阵营小羁绊
```

### 6.2 阵营效果草案

| 阵营 | 2 人触发 | 3 人触发 | 层数成长示例 |
|------|----------|----------|--------------|
| 守序 | 有效防御倍率提升 | 额外获得撤退返还与部署费用降低 | 有效防御倍率 `1.12 + 层数×0.003`，上限 4 倍；撤退返还、部署费用降低固定 |
| 混沌 | 暴击伤害倍率提升 | 额外获得暴击率与刷新费用降低 | 暴击伤害倍率 `1.15 + 层数×0.0035`，上限 4.5 倍；刷新费用降低固定 |
| 善良 | 每波开始全队回复倍率提升 | 额外获得开波护盾倍率 | 回复/护盾倍率 `1.1 + 层数×0.0032`，上限 4.2 倍 |
| 邪恶 | 攻击吸血倍率提升 | 额外获得击杀金币概率 | 攻击吸血倍率 `1.1 + 层数×0.0032`，上限 4.2 倍；击杀金币概率固定 |
| 中立 | 全队泛用属性倍率提升 | 额外获得最大 DP、胜利金币与商店刷新费用降低 | 泛用属性倍率 `1.05 + 层数×0.0025`，上限 3.5 倍；最大 DP、胜利金币、刷新费用降低固定 |

阵营收益尽量控制在“经济与数值偏好”层面。比如混沌可以强化暴击倍率和暴击率，但不应获得“随机改变技能形态”这种主机制效果；邪恶可以有攻击吸血和击杀收益，但不应变成完整的召唤/献祭玩法。

阵营中涉及商店价格、刷新费用、部署费用、胜利金币、击杀金币、初始 DP、最大 DP 的加成，均视作资源/经济项，不适用层数线性成长。它们只由触发档位、遗物或事件直接改写。

## 七、8 人部署与羁绊组合

战场部署角色数量上限暂定为 8 人。这个上限会直接决定羁绊组合的主流形态。

### 7.1 主流结构：6 主羁绊 + 3 小羁绊

```text
6 人主羁绊 + 3 人小羁绊 - 1 名重叠角色 = 8 个部署位
```

这是默认推荐玩法。玩家围绕一个瑞莫里诺盟约凑出 6 人主羁绊，获得完整机制；再用一个 3 人小羁绊补强核心数值。

示例结构：

```text
扭曲生命主羁绊 6
敏捷小羁绊 3

部署位：
1. 扭曲生命角色 A
2. 扭曲生命角色 B
3. 扭曲生命角色 C
4. 扭曲生命角色 D
5. 扭曲生命角色 E
6. 扭曲生命角色 F / 敏捷    # 重叠角色
7. 敏捷角色 G
8. 敏捷角色 H
```

其中 `扭曲生命角色 F / 敏捷` 同时贡献 1 点扭曲生命主羁绊和 1 点敏捷小羁绊，所以 8 个部署位即可同时完成 `6/6` 主羁绊与 `3/3` 小羁绊。

### 7.2 数值拼图结构：3 个 3 人小羁绊

玩家也可以放弃 6 人主羁绊，选择开启 3 个 3 人小羁绊，用多条数值曲线叠加来配合角色本体、装备和遗物。

```text
敏捷小羁绊 3
混沌小羁绊 3
邪恶小羁绊 3
```

由于单个角色可以拥有多个小羁绊标签，例如 `敏捷 + 混沌` 或 `敏捷 + 邪恶`，3 个小羁绊不一定需要 9 个部署位。这个路线的特点是机制变化较少，但数值密度高，适合依赖角色技能本体或遗物触发的阵容。

### 7.3 平衡基准

| 结构 | 机制强度 | 数值强度 | 设计定位 |
|------|----------|----------|----------|
| 6 主 + 3 小 | 最高 | 高 | 标准终局 Build |
| 3 主 + 3 主 + 3 小 | 中高 | 中高 | 双盟约混合 Build |
| 3 小 + 3 小 + 3 小 | 低 | 最高 | 数值拼图 Build |
| 3 主 + 多个 2 小 | 中 | 灵活 | 过渡期或应急 Build |

主羁绊负责打开机制上限，小羁绊负责把数值推高。小羁绊可以很强，但不能用数值强度反向替代主羁绊的机制辨识度。

## 九、数值与叠加规则

1. **层数只放大战斗数值**  
   羁绊层数范围为 `0-999`，常规公式为 `最终加成/倍率 = 档位基础值 + 层数 × 每层成长值`。适用对象包括攻击、生命、防御、攻速、暴击、伤害、治疗、护盾、减伤、异常抗性等。商店刷新花费降低、商店价格降低、部署费用降低、撤退返还、初始 DP、最大 DP、胜利金币、击杀金币等资源/经济项不适用层数线性成长。

2. **初级加成必须有可变数值**  
   每个已激活羁绊的第一档效果都应包含至少一条可随层数变化的数值，通常为百分比加成。例如 `物理攻击倍率 1.15 + 层数×0.0038`。如果某个主羁绊第一档是纯机制，例如“召唤藤蔓”，也需要给藤蔓的减速、持续时间、生命值或触发伤害配置层数成长。

3. **同类加成先相加，最后统一乘算**  
   例如攻击力最终值：`基础攻击 × (1 + 力量加成 + 装备加成 + 临时 Buff 加成)`。

4. **主羁绊机制触发后，再吃小羁绊数值修正**  
   例如游荡者的潜袭伤害属于主羁绊机制；潜袭最终伤害仍然可以被敏捷、力量、邪恶等小羁绊数值修正影响。

5. **经济收益设置单场上限**  
   击杀金币、胜利金币、刷新费用折扣需要设置软上限，避免某个经济阵营滚雪球过快。建议单场额外金币不超过基础奖励的 30%。因为经济项不吃层数，所以它们更适合由触发档位、遗物品质或路线事件来调整。

6. **技能冷却缩减设置全局上限**  
   所有来源合计冷却缩减不超过 40%，避免技能系统失控。

7. **防御与闪避分开限制**  
   防御适合稳定减伤，闪避适合波动收益。闪避建议上限 35%，否则自走棋战斗结果会过度随机。

## 十、Godot 实现落点

### 10.1 数据结构扩展

当前 `ClassTemplate` 已经承担职业模板职责，建议拆出更清晰的角色定义层：

```text
CharacterDefinition
├── character_id
├── display_name
├── class_group          # 主羁绊临时代号，例如 anmarit/remolino_law/moon_cult
├── subclass_id          # champion/hunter/evoker...
├── stat_tags            # ["DEX", "WIS"]
├── alignment_tags       # ["CHAOTIC", "NEUTRAL"]
├── class_template_id    # 指向现有 ClassTemplate 或未来的分支模板
├── rarity
└── skill_ids
```

`ClassTemplate` 保留为“职业/小分支战斗模板”，继续决定：

- 部署费用
- 基础属性
- 攻击模式
- 攻击范围
- 索敌范围
- 姿态修正
- 技能列表
- 职业特性参数

### 10.2 新增 SynergyDefinition

```text
SynergyDefinition
├── synergy_id
├── display_name
├── type                 # MAIN_NATION / MINOR_STAT / MINOR_ALIGNMENT（MAIN_NATION 暂为历史命名）
├── tag                  # anmarit / remolino_law / DEX / LAWFUL
├── thresholds           # 主羁绊 [3, 6]；小羁绊 [2, 3]
├── layer                # 当前层数，0-999
├── layer_sources        # 星级/遗物/事件/奖励等来源明细
├── scalable_modifiers   # 随层数线性成长的战斗数值
├── fixed_modifiers      # 不随层数成长的资源/经济数值
└── mechanic_id          # 主羁绊使用，如 anmarit_poison
```

推荐的 `scalable_modifiers` 数据形态：

```text
{
  "stat": "burning_damage_multiplier",
  "curve": "linear_cap",
  "base": 1.4,
  "per_layer": 0.008,
  "max_value": 9.5
}
```

推荐的 `fixed_modifiers` 数据形态：

```text
{
  "resource": "shop_discount_percent",
  "value": 0.05
}
```

资源/经济项必须进入 `fixed_modifiers`，不允许配置 `per_layer`。

### 10.3 新增 SynergyManager

建议路径：

```text
game/scripts/synergy/synergy_manager.gd
game/scripts/synergy/synergy_definition.gd
game/scripts/synergy/synergy_effects.gd
```

核心职责：

```text
SynergyManager
├── listen deployed_units_changed
├── collect tags from deployed HeroUnit
├── calculate active tiers and layers
├── emit synergy_changed(active_synergies)
├── apply scalable numeric modifiers to UnitBase
├── apply fixed resource modifiers to ResourceManager/RoguelikeManager
└── dispatch mechanic hooks to profession-specific effects
```

当前实现：

- `SynergyManager.get_active_main_effects()` 输出七个主羁绊的机制参数，包含当前档位、层数和线性成长后的实际数值。代码里的 `MAIN_NATION`/`main_nation` 暂作历史类型名保留。
- `UnitBase` 在普攻和伤害技能命中后触发主羁绊命中钩子；治疗技能不触发毒、自然值、灼烧或禁忌标记。
- 瘴林威胁使用 `anmarit_poison` 状态：攻击叠加毒层，毒层随时间衰减并按秒造成状态伤害，6 人档改为小范围群体 DOT。
- 扭曲生命使用 `laferida_nature` 与 `laferida_slow` 状态：攻击积累自然值，满条后清空并施加减速，6 人档额外造成基于参与积累英雄最高攻击力的自然伤害。
- 龙焰吐息使用 `naka_burn_value` 与 `naka_burning` 状态：攻击提升由 `attack_multiplier` 直接进入数值管线，命中积累灼烧值，满条后点燃；6 人档对燃烧目标增伤并有概率触发范围爆炸。
- 骑士律法在 `receive_attack_damage` 中处理：盟约成员受击时按被攻击者防御先结算实际伤害，再按生命百分比均摊给所有存活成员；6 人档对攻击者造成无视防御律法反击。
- 窥探禁忌在伤害前挂 `moon_forbidden_mark`，保证被一击击杀的敌人也能触发死亡爆发；伤害后检查 6 人档处决阈值。
- 不灭战壕在受击入口判定闪避，闪避成功后 6 人档挂 `kroen_counter` 短时增伤。
- 十一长诗由盟约成员周期性向攻击范围内友军写入 `tro_poem_sources` 属性祝福；6 人档在成员释放技能后概率减少范围内友军技能冷却。

### 10.5 UI 展示

在战斗 UI 中新增一个羁绊面板：

- 画面顶部中间显示拥有的羁绊，图标为正方形，已激活的为天蓝色，未激活的为灰色
- 每个羁绊图标的上方有激活进度提示灯，形状为2/3个扁长小矩形，左右两边与图标正方形对齐，中间有空隙
- 图标居中排列，超过最长范围时增加一排空间
- 羁绊层数只使用单一的数字，在图标内最底部居中显示，增强与图标的对比度
- 羁绊显示顺序为激活的优先，其次层数高的优先，再次是主羁绊优先，羁绊间按文档中的顺序排序

- 羁绊说明显示羁绊图标，羁绊名称，已激活人数`2/3`，详细说明，该盟约对应的角色图标（使用与商店相同的图标）
- 酒馆招募卡上显示该角色能补齐的羁绊，例如 `游侠`、`敏捷`、`中立`

- 实现阵营资源加成，资源项固定不随层数成长
- 在战斗开始、部署变化、撤退时刷新属性
- 在胜利结算时应用金币/刷新/招募类奖励

### 阶段 3：扩展七个主羁绊机制

优先实现当前 7 个盟约机制原型：

1. 瘴林威胁：中毒、瘴气 DOT、毒层衰减、6 人小范围扩散
2. 扭曲生命：自然值、爆条减速、6 人最高攻击力结算的自然伤害
3. 龙焰吐息：攻击提升、灼烧值、点燃、燃烧增伤与额外爆炸
4. 骑士律法：防御提升、生命比例均摊、6 人律法反击
5. 窥探禁忌：易伤、死亡爆发、6 人禁忌处决
6. 不灭战壕：移速、闪避、6 人闪避后增伤
7. 十一长诗：范围属性祝福、6 人技能冷却缩减

## 十三、后续可扩展方向

1. **小分支专属遗物**  
   小分支不直接成为羁绊，但可以与肉鸽遗物绑定。例如“战斗大师手册”只强化战士-战斗大师角色。

2. **阵营事件节点**  
   地图节点可以检测队伍阵营倾向，例如守序队伍更容易获得秩序神殿奖励，混沌队伍更容易触发高风险高收益事件。

3. **多职业角色**  
   高稀有度角色可以拥有双盟约背景，例如“龙焰吐息/扭曲生命”的奥法骑士，同时贡献两个主羁绊，但部署费用更高。

4. **职业反制敌人**  
   敌方阵容也可以携带弱羁绊标签，让玩家在路线选择时根据已有 Build 判断风险。
