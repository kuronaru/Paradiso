# 主羁绊

## 国家背景

瑞莫里诺（remolino）是泰伯珑大陆最大的国家，面积大概相当于现实中的美国，是一个远近闻名的契约之国，该国重视法律与契约，恪守本国的规则，时间观念很强，甚至有些反人性，瑞莫里诺有一本法典，该法典会自动对首都城范围内的犯罪行为进行实时惩罚，并为犯罪者打上标记，犯罪者会因二次犯罪得到更严重的惩罚，瑞莫里诺的首都位于莱茵刻伯，是一个繁盛的沿海都城，背靠贯穿全国的天连江主干道，地理位置优越，自皇帝胡烈家族即位之后，推行民主化改革，目前国家正处于经济上行期。瑞莫里诺的通用货币是法司（铜币），布朗和里金，1里金=1000布朗 1布朗=60法司，还有一种珍惜货币：维斯塔焰石（Vesta's Pyrum），由圣火教廷发行，数量稀少，价值高昂。瑞莫里诺拥有完备的骑士军纪，骑士一旦背誓将会获得犯罪者烙印，其家属也会受牵连，骑士享有很高的待遇。同时，因为都城内的法典严格管理，都城外的反抗者和犯罪者比较一直在活动，莱因城成立了专门的围剿骑士团去处理这些组织。瑞莫里诺注重魔法的发展，同时也不排斥科学，是一个比较包容但又严格的国家，目前瑞莫里诺由九大荣誉贵族分封管辖，同时生活着很多种族，且瑞莫里诺的动物有一部分属于政府，起到法典的监视作用，总的来说，这是个法律高于王权的古板国家，同时又很强大

## 羁绊效果

```
模板说明
国家名称：羁绊名称（羁绊流派类型）
3人激活效果
6人激活效果
```

1. 安马里特森林（尤尼乌斯伯爵领）：瘴林威胁（适合应对怪海，也能造成可观伤害）
- 3人：英雄攻击附带【层数系数】%攻击力的毒属性层数，层数随时间衰减，根据层数造成dot属性伤害，层数可累加
- 6人：dot属性伤害变为小范围群体伤害

2. 拉费里达平原（洛朗领地）：扭曲生命（适合应对高移速偷家型敌人）
- 3人：英雄攻击积累自然值，积累满自然值时清空自然值（爆条）并造成造成【层数系数】%减速
- 6人：积累满自然值额外造成【层数系数】%攻击力的属性伤害（取所有积累了自然值的英雄中的最高攻击力作为结算的基础攻击力）

3. 拉贝尔领地——考特火山：龙焰吐息（适合高输出）
- 3人：英雄攻击力提升【层数系数】%，攻击附带灼烧值，积累满灼烧值时清空灼烧值（爆条）并点燃敌人
- 6人：英雄对燃烧状态的敌人造成伤害提升【层数系数】%，且有【层数系数】%概率额外造成一次爆炸伤害

4. 莱茵刻伯（瑞莫里诺首都，兰博明公爵领）：骑士律法（适合应对高伤害的精英和头目）
- 3人：英雄防御力提升【层数系数】%，羁绊成员共同承受伤害，伤害经过受攻击的英雄防御计算后化为百分比伤害均摊（即所有成员均受到相同百分比的伤害）
- 6人：每次攻击羁绊成员的敌人会受到来自律法的【层数系数】%所有成员攻击力之和的伤害，该伤害无视防御

5. 月神邪教：窥探禁忌（适合应对怪海和高防御敌人）
- 3人：敌人受到的伤害提升【层数系数】%，如果敌人受到攻击3秒内死亡，对周围造成一次【层数系数】的范围伤害
- 6人：敌人受到禁忌魔法的诅咒，如果敌人受到英雄攻击3秒内血量低于英雄【层数系数】%攻击力，立即受到诅咒而死

6. 克罗恩伯爵领，沙特尔地区：不灭战壕（适合闪避反击和快速抢点）
- 3人：英雄移动速度提升【层数系数】%，根据移动速度获得闪避几率
- 6人：英雄成功闪避后【层数系数】秒内获得【层数系数】%伤害提升

7. 特罗群岛（金雀伯爵领）：十一长诗（适合加成友方，塑造超强核心英雄）
- 3人：羁绊成员会给攻击范围内的友方提供加护，使其获得自身【层数系数】%全属性的提升
- 6人：羁绊成员释放技能时有【层数系数】%概率使攻击范围内的所有友方缩短【层数系数（阶梯函数）】秒技能冷却
